# Чеклист для деплоя на Selectel

## Перед деплоем

- [ ] Создан VPS сервер в Selectel (минимум 2GB RAM, 2 CPU, 20GB SSD)
- [ ] Настроен SSH доступ к серверу
- [ ] Установлены Docker и Docker Compose
- [ ] Подготовлен домен (если нужен)
- [ ] Создан файл `.env` с правильными настройками
- [ ] Настроены SSL сертификаты (для production)

## Настройка проекта

- [ ] Клонирован репозиторий на сервер
- [ ] Настроен файл `.env`:
  - [ ] POSTGRES_PASSWORD - сильный пароль
  - [ ] SECRET_KEY - минимум 32 символа
  - [ ] CORS_ORIGINS - список разрешенных доменов
  - [ ] ALLOWED_HOSTS - список разрешенных хостов
- [ ] Скопированы SSL сертификаты в `nginx/ssl/`
- [ ] Использована production конфигурация nginx (`nginx.prod.conf`)

## Запуск

- [ ] Запущены контейнеры: `docker-compose -f docker-compose.prod.yml up -d --build`
- [ ] Проверен статус: `docker-compose -f docker-compose.prod.yml ps`
- [ ] Проверены логи на ошибки
- [ ] Проверена доступность приложения по IP/домену

## Настройка домена

- [ ] Добавлена A-запись для основного домена
- [ ] Добавлена A-запись для www поддомена
- [ ] Проверена доступность по домену

## Безопасность

- [ ] Изменены пароли по умолчанию
- [ ] Настроен файрвол (UFW)
- [ ] Настроены SSL сертификаты
- [ ] Проверена работа HTTPS
- [ ] Настроен автозапуск (systemd service)

## Мониторинг

- [ ] Настроены логи
- [ ] Проверена работа резервного копирования БД
- [ ] Настроено автоматическое обновление SSL сертификатов

## Тестирование

- [ ] Проверена регистрация пользователей
- [ ] Проверен вход администратора
- [ ] Проверена работа каталога товаров
- [ ] Проверена работа корзины
- [ ] Проверена работа заказов
- [ ] Проверена админ панель
- [ ] Проверен доступ к API документации (только для админов)
- [ ] Проверена страница 404

## После деплоя

- [ ] Создан первый бэкап БД
- [ ] Настроен cron для регулярных бэкапов
- [ ] Документированы учетные данные (в безопасном месте)
- [ ] Настроены уведомления о проблемах (опционально)
